control_task 功能说明
作用
1 kHz 主控制任务：读遥控器挡位、IMU、红外测距和轨迹规划结果，驱动俯仰轴、偏航轴、跟随轴三个电机，实现「上电保持 → 锁定待命 → 红外触发避障 → 复位 → 追踪轨迹」的自动流程。

上电流程
初始化遥控器、红外模块、CAN 总线后进入 1 ms 主循环。每拍依次：更新姿态检测 → 读取轨迹快照 → 刷新红外状态 → 按右拨杆挡位分派控制 → 命令三个电机 → 统一发 CAN。

挡位行为
中挡：主工作模式，进入三段状态机（见下）。

上挡：空实现，电机保持上一拍输出。

挡位切换瞬间清空俯仰、偏航四路 PID 状态，防止突跳；切入中挡时记录入口时刻并重置避障状态机。

中挡三段状态机
启动保持期（前 2 秒）：俯仰、偏航锁在固定角度，仅做姿态稳定，红外不判定，同时持续刷新 IMU 参考基准。

锁定待命：姿态保持不变，连续两拍检测到近距离（<60 cm）后触发避障。

避障时间轴（触发后按毫秒计时）：

前 3 秒：俯仰下压让出通路，偏航锁定；

3～6 秒：俯仰回到保持角，偏航锁定；

6 秒后：俯仰保持，偏航开始跟随轨迹，并叠加速度、加速度前馈。

避障一旦触发不会自动退出，需切挡复位。

三轴控制方式
俯仰轴：位置环 + 速度环，叠加随姿态角变化的余弦重力补偿（抵消负载重力矩）。

偏航轴：位置环 + 速度环；仅在轨迹追踪阶段叠加前馈。

跟随轴（减速电机）：直接按 IMU 横滚角乘减速比作为位置目标，双环跟随，不走状态机。

输入 / 输出
输入：右拨杆挡位、IMU 姿态与角速度、红外距离、轨迹六元组（位置/速度/加速度）。

输出：三轴力矩；同时把红外距离与有效性写给绘图任务只读。

外部依赖
轨迹任务提供 680 ms 周期曲线。

以上为match分支内容，10.24.5.09分支提供避障的另一种方案：不再依据时间进行状态控制，而是进入避障状态后一段时间没有障碍物就会自动抬起，并且可重复避障。
